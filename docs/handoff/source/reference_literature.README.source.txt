# Reference Literature & Published-Style Summary Materials

## Background papers

A working bibliography Sunny compiled on causal attribution, fault,
intention, and moral judgment in children and adults — includes Hamlin
(2007, social evaluation by preverbal infants), Nobes et al. (negligence/
intention/outcome and moral judgment), Rose (2021/2025, "Cause and burn" /
"Cause and fault," and the causal-verb-mapping paper this project builds
on directly), McClure et al. (voluntary vs. physical causes), Alicke
(1992, "Culpable Causation"), Shultz (1986), Schleifer et al. (1983),
Cushman/Sheketoff/Wellman-Carey (2013), Naigles (1990, syntax and verb
learning), Wellman & Woolley (2022), and Hamlin et al. (2011, infants'
reactions to antisocial others). Useful background/citations for any
write-up or talk built from this project's results.

## `published_summary_figures_and_pcard_pdf_tool/`

This was found on Sunny's Desktop as a folder called "Result figures,"
containing what appear to be publication/talk-ready summary figures
(`Fig.1a/1b/2/3a/3b/4a/4b/5.png`) plus a small unrelated utility script,
`generate_pdf.py`, and its output `summary.pdf` — **that script and PDF are
not a research artifact**: reading the script shows it assembles a Markman
Lab P-card purchase summary (a Prolific participant-payment receipt cover
sheet, IRB #59627, dated 5/12/26) by merging itself with two Prolific
receipt PDFs that live one level up from this folder on Sunny's Desktop
(referenced as `../prolific_summary_*.pdf` in the script, not included
here since they are financial/participant-payment records). It's included
here only because it was physically inside the same folder as the
figures; **it is unrelated to the figures and should probably be moved to
lab financial records rather than treated as part of the research
archive.**

**Which study/studies `Fig.1`–`Fig.5` actually correspond to was not
determinable from the folder alone** (no accompanying code or labels beyond
the image filenames), since they may be an already-finalized,
publication-styled version of one of the plot sets elsewhere in this repo
(most likely Study 1 or Study 2, given the fault/causation/responsibility-
style naming pattern in the other plot folders) rather than a fifth,
separate result. Verify against the plot contents before using these in a
talk or paper.
