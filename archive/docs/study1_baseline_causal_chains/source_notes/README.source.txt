# Study 1 (Verbal) — Archive

Complete contents of https://github.com/SunnyZ-cs/lookit_material, preserved
in full. This repo's own commit history is the finest-grained record of how
it changed over time.

- `children_pilot1_exp1mats_with_punish/` — an earlier pilot version of the
  Study 1 children's materials: multiple question JSON variants
  (`exp1.json`, `exp1_fault_first.json`, `punishment_study_final.json`,
  `punishment_study_v2.json` — different question-order/wording drafts),
  its own `img/`, `mp4/`, `response_images/`, and an exported Lookit
  response file. **That response file's name includes the word
  "identifiable" — treat it as participant data.**
- `children_pilot1_psych_verb_exp2/` — despite the "exp2" in the name, this
  folder is physically inside the Study-1 archive repo; it appears to be an
  early pilot of the causal-verb (psych-verb) materials that eventually
  became Study 2. Whether this is more properly Study 1's or Study 2's
  history is unresolved — it's been left exactly where it was found
  (inside this repo) rather than moved, to avoid guessing wrong about its
  provenance.
- `LICENSE` — this repo was originally created from Lookit's own
  stimuli-hosting template repository (see its `README.md`, included),
  which explains the generic instructions inside it about forking and
  uploading stimuli via the GitHub web UI — that boilerplate is not specific
  to this project and can be ignored for handoff purposes.
