# Study 1 — Baseline causal chains — older versions

Start with [the current study guide](../../../current/docs/study1_baseline_causal_chains/README.md) unless you have a specific task involving these older files. Keep archived files unchanged.

This folder contains earlier child versions of the chain/punishment studies and related studies of causal verbs. It also includes the adult `pilot8/chainspilot8-responses.csv` dataset and five child pilot1 tables. The child parsing and file-renaming helpers are under Python.

The older psychological-verb versions named `exp1`, `exp2` and `exp3` stay together here. We still need to confirm whether some, especially `exp2`, belong with Study 1 or Study 2 when comparing results. Do not use these older pilot data in place of the current child dataset.
