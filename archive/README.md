# Older pilots and previous versions

Start with your [current study](../README.md) unless you have been assigned a task involving an older version. A pilot is an early study used to try out a design or method.

Use this archive to compare earlier experiment materials, inspect older datasets or locate a specific result. Keep these files unchanged. Version names such as `pilot1`, `v2` and `v4` help distinguish experiments that may look similar but differ in important ways.

- [Study 1](docs/study1_baseline_causal_chains/README.md)
- [Study 2](docs/study2_intention_causal_chains/README.md), including early adult pilots with responses summarized by hand
- [Study 3](docs/study3_nonverbal/README.md)
- [Single cause](docs/single_cause/README.md)
- [Other older files to identify](docs/unclassified_historical/README.md)

As in `current/`, code, data, study information and figures are separated by study and age group. Check with the project lead before treating an older dataset as part of a current study.
