# Early Adult Pilots (Hand-Coded), Pilots 3 & 4

Very early adult pilots of the verbal causal-chain paradigm, predating the
current jsPsych-based Studies 1/2. Slide-based stimuli (PowerPoint), with
responses hand-coded rather than collected/analyzed programmatically.

- `pilot3_chain_mirror_adults.pptx` — the mirror/chair chain scenario slide
  deck used in pilot 3.
- `pilot3_response_distribution_hand_coded.pdf` — hand-coded response
  distribution for pilot 3.
- `pilot4_mirror_fence_intentional.pptx` — pilot 4's slide deck, adding the
  intentional manipulation (a precursor to Study 2).
- `pilot4_response_distribution_hand_coded.pdf` — hand-coded response
  distribution for pilot 4.

Kept for historical continuity/completeness per David's request to preserve
all earlier pilots, even ones using a different (slide-based, hand-coded)
methodology than the current studies.
