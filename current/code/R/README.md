# R analysis

The original R analysis files for these studies are not currently available in this repository. This folder contains only this README.

R is a programming language used for statistics. An R Markdown (`.Rmd`) file combines explanations, R code and results in one document.

Do not create replacement analyses by guessing from the figures. Once the relevant data and analysis decisions are confirmed, we will create a single project-level R Markdown file that reads datasets using relative paths and saves figures into the corresponding `current/figures/` folders. Relative paths describe locations within the project instead of locations on a particular person's computer.

See the [project overview](../../../README.md) and your study guide for the next data and analysis tasks.
