# Adult MediaPipe pipeline

[local/process_videos_mediapipe.py](local/process_videos_mediapipe.py) is the processor associated with the supplied adult n61 pilot in the handoff notes. [sherlock/](sherlock/) preserves the cluster adaptation and its input/merge helpers; that adaptation was not validated live.

The adult video CSV is a secure external recording export, not a repository dataset. Paths, package versions and output/cohort matches remain unresolved. [Original notes](../../../../docs/study3_nonverbal/adults/source_notes/mediapipe_sherlock/README.source.txt) and the [pipeline audit](../../../../../docs/NONVERBAL_REPRODUCIBILITY.md) document the limits.
