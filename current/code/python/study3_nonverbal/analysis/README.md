# Available looking-time analysis

`unfair_punishment_analysis.py` compares looking at the punished character across fair and unfair punishment situations in chain and single-cause trials. It is the only distinct final-analysis script currently available here; two identical copies are kept:

- [Copy with the batch-3 materials](children_repilot_batch3_with_single_cause_n29/unfair_punishment_analysis.py).
- [Copy with the analysis/report materials](from_analysis_code_and_reports/unfair_punishment_analysis.py).

The script reads a file location on a previous computer. Before running it, confirm the correct [batch-3 input table](../../../../data/study3_nonverbal/children/children_repilot_batch3_with_single_cause_n29/icatcher_summary_combined.csv), review its analysis choices with the project lead, and plan a relative input path. Do not edit both copies independently.

The [existing reports](../../../../docs/study3_nonverbal/children/reports/) also describe looking before punishment, changes in looking over time, first looks, age comparisons and individual children. We do not yet have all of the scripts for those results or their figures. Recover the original scripts if possible before writing a new analysis.
