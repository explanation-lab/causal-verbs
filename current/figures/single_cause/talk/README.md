Generated by the [shared R Markdown workflow](../../../code/R/causal_verbs.Rmd), using the supplied exp7 child export and the existing 32-row adult CSV for the developmental figure; the pooled secondary summary remains children only. One direct causal agent is judged in each scenario. Yes=1 and No=0; average Bike/Mirror within participant × condition × measure, then average participant means. These are ordinary endorsement rates, with no relative-attribution score. The developmental figure has the same dashed 50% visual reference as Study 2; that midpoint is not a chance-model assumption.

## Sample and filtering

970 raw rows represent 97 sessions and 97 unique children aged 3–6. One withdrawn session is excluded using `include_in_analysis` plus withdrawal/exclusion/completion information. There are no repeat child IDs. The remaining 96 children supply 768 test answers. All 194 warmup rows are excluded from scientific summaries. `completed` is False throughout and is ignored for inclusion; `included_in_summary` is also ignored.

The Rmd recalculates the flow and cell Ns, audits repeats and stops for review if this supplied snapshot does not match. It uses fixed-seed participant bootstraps with 5,000 replicates and pointwise 95% percentile intervals. The secondary summary pools child means across ages with equal participant weights within condition; it is not age-standardized. Intervals describe means, not formal between-condition or between-study tests.
