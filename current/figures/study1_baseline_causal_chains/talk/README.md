# Study 1 descriptive talk figures

Generated by [causal_verbs.Rmd](../../../code/R/causal_verbs.Rmd). This is a new reconstruction from available data, not recovered original plotting code. Historical figures outside this folder are unchanged. These raw Yes-response figures remain backup outputs; the [change-from-baseline comparison](../../study_comparison_baseline_change/README.md) is now the main talk figure.

[Full PNG](study1_yes_responses_full.png) · [Vector PDF](study1_yes_responses_full.pdf) · [Builds](builds/)

The figure combines 100 adults with 211 unique children aged 3–9 from the supplied Study 1 snapshot.

The four panels are Caused, Lexical, Fault and Punish. Each panel has two series: Distal is Set1 red (`#E41A1C`), Proximal is Set1 blue (`#377EB8`). Both lines are solid; distal points are filled circles and proximal points are filled squares.

The y-axis is `"Yes" Responses (%)`, with ticks at 0%, 25%, 50%, 75% and 100% and a dashed horizontal line at 50% in every panel/build. Numerical tables retain proportions from 0 to 1. Each agent’s original Yes=1/No=0 response is retained: both yes contributes 1 to each role, and neither contributes 0 to each role. Available Bike/Mirror answers are averaged within participant × measure × role before group averaging. Missingness stays question-specific. Participants receive equal weight. The report verifies every plotted mean and contributing N, with a separate descriptive both/neither audit.

Lines connect child age means; adults are separate endpoints labeled Adult. Intervals are fixed-seed participant bootstrap 95% intervals. Small fixed horizontal offsets separate overlapping roles/conditions.

All outputs are 16 × 12.8 inches; PNGs are 3840 × 3072 pixels. Build 00 is the complete blank four-panel scaffold. Builds 01/02 add Caused adults/children, 03/04 Lexical, 05/06 Fault and 07/08 Punish. Each reveal includes both role series. PDF and PNG exist for every build. Build 08 equals the full figure. Axes, panel sizes, legends, margins, positions and previously revealed results stay fixed.

These are uncapped descriptive child samples, not finalized preregistered samples. See the [running guide](../../../code/R/README.md) and [review packet](../../../code/R/REVIEW.md) for the cap rule, input provenance, eligibility decisions and unresolved scientific handoff gaps.
