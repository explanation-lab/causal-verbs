# Single cause — adults

Start with the [study guide](../README.md) for the scientific question and what participants do.

The [adult pilot dataset](../../../data/single_cause/adults/single_cause_pilot1-responses.csv) is already present with 32 rows. The reported analysis used 30 participants. The [audit](ANALYSIS_AUDIT.md) found 32 complete, unique rows and no verified exclusion rule. All source rows remain unchanged. The current working developmental figure uses all 32 adults, 16 per condition, because no defensible historical exclusion rule was recovered; the reported N=30 subset remains unidentified.

No separate preregistration or original plotting code is currently available. The study guide explains the questions and next tasks.
