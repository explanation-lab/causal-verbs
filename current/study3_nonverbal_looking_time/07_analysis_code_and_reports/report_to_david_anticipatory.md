**Event timestamps** (frame-by-frame from the GIFs; video time, bullseye at 0 s): causal event repeats 3× during 3–17 s (last cube-break complete ~16.5 s); scene static with both characters starred 17–19 s; authority departs center at exactly 19.0 s = first moment the target is knowable; star removal 20.3–21.3 s; freeze at 21.76 s. **Anticipatory window = 17–19 s**: outcome known, characters visually identical, target unknowable. Sanity check passed — pre-target looking doesn't depend on which character is later punished.

**The context effect is there, but inverted relative to the punishment-anticipation prediction:**

- Single cause: distal-looking 0.69 [0.57, 0.82], d = 0.94, p = .005 — children look strongly at the **bystander**, not the expected punishment target.
- Chains: 0.56 [0.38, 0.74] — near chance.
- Context difference: −0.13 [−0.34, 0.08], d = −0.48.
- Expected-punishment-side score: 0.44 overall — below, not above, .50.
- First trial only: same pattern, slightly stronger (0.68 / 0.79) — present before any punishment has ever been observed.

**Reading:** children don't scan toward who will be punished; they orient toward the character they expect to be spared — clearly the bystander in single cause, ambiguous in chains. That's causal-structure sensitivity expressed as innocence-orientation, and it's continuous with the post-punishment star-keeper preference. A caveat for Monday: in single cause the bystander is also the only character that never moves, so a low-motion/novelty account needs ruling out (a control with irrelevant bystander motion would do it).

Your proposed redesign fits this well — the neutral-cue anticipatory interval would let us test innocence-orientation vs punishment-anticipation cleanly, and removing the star asymmetry post-punishment is clearly right.
